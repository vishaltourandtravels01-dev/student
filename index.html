📤 1. अपनी फाइल चुनें

फोटो चुनते ही पहले Crop / Resize करने का विकल्प मिलेगा। उसके बाद ही फोटो ऑर्डर में जुड़ेगी।
मोबाइल पर Gallery/File Picker खुलेगा। Photo या PDF चुनें → Document Scanner Editor खुलेगा।
📑 इस dropdown में कोई भी print type चुनें — उसके Photo/PDF पर पहले यही Document Scanner Editor खुलेगा। सभी print types में ✂️ Crop / 4-Corner Crop, ↻ Rotate, 🎨 Color Filter, 🧽 Eraser, ✍️ Signature और 💧 Watermark उपलब्ध रहेंगे। 📸 पासपोर्ट फोटो चुनने पर edited photo से A4 पर 6 passport-size photos का layout अपने-आप बनेगा।
✂️ Crop / 4-Corner↻ Rotate🎨 Color Filter🧽 Eraser✍️ Signature💧 Watermark
🪪 ID / Aadhaar — Front और Back एक ही पेज पर
पहले Front फोटो चुनें → Crop/Resize करें → फिर Back फोटो चुनें → Crop/Resize करें। अंत में दोनों को एक A4 पेज पर वास्तविक Aadhaar आकार (85.60 × 53.98 mm) में लगाया जाएगा। Print में 100% / Actual Size रखें।
💳 PAN Card / Identity Card — A4 पर Actual Card Size
Photo चुनें → Document Scanner Editor में Crop/4-Corner, Rotate, Color Filter, Eraser, Signature और Watermark लगाएँ → फिर A4 पर 85.60 × 53.98 mm actual card size में automatically तैयार होगा।
