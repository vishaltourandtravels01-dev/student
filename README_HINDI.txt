FINAL30 v14 - PDF Color Adjust Fix

v13 की सभी settings/features जस की तस रखी गई हैं।
इस update में केवल PDF Color Adjust का ENOENT crash fix किया गया है।
- pdftoppm उपलब्ध हो तो उपयोग होगा
- Windows पर Ghostscript (gswin64c/gswin32c) उपलब्ध हो तो fallback उपयोग होगा
- कोई PDF renderer उपलब्ध न होने पर app error नहीं देगा; PDF सुरक्षित रखेगा और editor preview में Color Adjust दिखेगा

बाकी Document Scanner, Crop/4-Corner, Rotate, Color Filter, Eraser, Signature, Watermark, PAN/Identity, Aadhaar, Passport, printer और payment settings नहीं हटाई गई हैं।


FINAL30 v15: Color Filter चुनने के तुरंत नीचे Color Adjust controls दिखते हैं। Brightness/Contrast/Saturation/Temperature/Exposure/Sharpness/Shadows/Highlights/B&W adjustments चुने हुए filter के साथ JPG/PNG/PDF और सभी print types में काम करते हैं। पुरानी v14 settings बरकरार हैं।
